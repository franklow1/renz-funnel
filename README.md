# Renz Style Solve

The live funnel for lorenzosegor.com, served as two files.

## The quiz + sales page

```html
<div id="rz-mount"></div>
<script src="https://franklow1.github.io/renz-funnel/funnel.js" defer></script>
```

## The thank you page

```html
<div id="rz-thanks-mount"></div>
<script src="https://franklow1.github.io/renz-funnel/thanks.js" defer></script>
```

Paste each block once, into its own page. After that a push to `main` updates the live
pages within about a minute, with nothing to re-paste.

Both `.js` files are generated by `build-loader.py` from the funnel source and are
overwritten on every build, so neither is ever edited by hand.
